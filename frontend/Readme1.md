# 🎨 GlowConnect - Frontend

Social Media Web Application built with React.js, Tailwind CSS, and Axios.

---

## 🚀 Tech Stack

- **React.js** - UI Library
- **Tailwind CSS** - Styling Framework  
- **Axios** - HTTP Client
- **React Router** - Navigation
- **React Context** - State Management
